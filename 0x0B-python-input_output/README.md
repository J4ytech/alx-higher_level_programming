# 0x0B. Python - Input/Output

## Description
This project covers reading and writing files in Python, working with JSON, and building classes that can be converted to and from JSON. It also includes algorithmic tasks like Pascal’s Triangle and log parsing.

## Learning Objectives
- Read and write files in Python
- Understand JSON serialization/deserialization
- Work with dictionaries and classes
- Implement Pascal’s Triangle
- Parse logs and compute metrics

## Files
- `0-read_file.py` → Read a text file and print to stdout
- `1-write_file.py` → Write a string to a file
- `2-append_write.py` → Append a string to a file
- `3-to_json_string.py` → Convert object to JSON string
- `4-from_json_string.py` → Convert JSON string to object
- `5-save_to_json_file.py` → Save object to file in JSON
- `6-load_from_json_file.py` → Load object from JSON file
- `7-add_item.py` → Add arguments to list and save
- `8-class_to_json.py` → Return dictionary description of object
- `9-student.py` → Student class with `to_json()`
- `10-student.py` → Student class with filtered `to_json(attrs)`
- `11-student.py` → Student class with `reload_from_json()`
- `12-pascal_triangle.py` → Generate Pascal’s Triangle
- `100-append_after.py` → Insert text after lines containing a string
- `101-stats.py` → Parse logs from stdin and compute metrics
