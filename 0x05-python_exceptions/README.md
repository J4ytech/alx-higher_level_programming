# 0x05. Python - Exceptions

## Description
This project focuses on error handling in Python using `try`, `except`, `else`, and `finally`. Learning how to manage exceptions is crucial for writing robust code that can handle unexpected inputs or runtime errors without crashing.

## Learning Objectives
* Why exceptions in Python are important.
* When to use exceptions.
* How to handle exceptions using `try` and `except`.
* How to raise built-in exceptions.
* When to use `finally` and `else`.

## Requirements
* **Operating System:** Ubuntu 20.04 LTS
* **Language:** Python 3.8.5
* **Style Guide:** Pycodestyle (version 2.8.*)
* **Execution:** All files must be executable.

## File Summary

| File | Description |
| :--- | :--- |
| `0-safe_print_list.py` | Prints $x$ elements of a list safely. |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()`. |
| `2-safe_print_list_integers.py` | Prints the first $x$ elements of a list that are integers. |
| `3-safe_print_division.py` | Divides 2 integers and prints the result. |
| `4-list_division.py` | Divides element by element 2 lists. |
| `5-raise_exception.py` | Raises a type exception. |
| `6-raise_exception_msg.py` | Raises a name exception with a message. |
| `100-safe_print_integer_err.py` | Prints an integer and returns True; otherwise prints error to `stderr`. |
| `101-safe_function.py` | Executes a function safely and prints error to `stderr` on failure. |
