# 0x0A. Python - Inheritance

This project covers the fundamentals of Object-Oriented Programming (OOP) in Python, specifically focusing on class inheritance, subclasses, method overriding, and input validation.

## Files

| File | Description |
| --- | --- |
| `0-lookup.py` | Returns the list of available attributes and methods of an object. |
| `1-my_list.py` | A class `MyList` that inherits from `list` with a public instance method to print the sorted list. |
| `2-is_same_class.py` | Returns `True` if an object is exactly an instance of the specified class. |
| `3-is_kind_of_class.py` | Returns `True` if an object is an instance of, or inherited from, the specified class. |
| `4-inherits_from.py` | Returns `True` if an object is an instance of a class that inherited (directly or indirectly) from the specified class. |
| `5-base_geometry.py` | An empty class `BaseGeometry`. |
| `6-base_geometry.py` | A class `BaseGeometry` with a public instance method `area()` that raises an exception. |
| `7-base_geometry.py` | Adds `integer_validator` to `BaseGeometry` to validate method inputs. |
| `8-rectangle.py` | A class `Rectangle` that inherits from `BaseGeometry` and validates inputs. |
